A comprehensive collection of Data Structures and Algorithms implementations developed during the **MScIT Semester 1** laboratory coursework. This repository covers fundamental to advanced concepts in computer science using the C language.

## 📁 Repository Structure

The lab work is organized into **10 core sessions**, with over 80+ programs covering various algorithmic challenges:

| Session | Modules | Topics Covered |
| :--- | :--- | :--- |
| **01** | Fundamentals | Simple Interest, Temperature Conversion, Basic Logic |
| **02** | Control Flow | Decision Making, Loops, Patterns |
| **03** | Stacks & Queues | Linear/Circular Queue, Stack implementation |
| **04** | Dynamic Arrays | Matrix Operations, Memory allocation |
| **05** | Linked Lists | Singly Linked Lists, Node management |
| **06** | Complex Lists | Doubly Linked Lists, Circular Linked Lists |
| **07** | Trees | Binary Search Trees (BST), Insertion, Search |
| **08** | Graph DS | Graph Representation, BFS, DFS |
| **09** | Sorting | Bubble, Selection, Quick, Merge Sort |
| **10** | Searching | Linear Search, Binary Search, Hashing |

## 🛠️ Tech Stack
- **Language:** C (C99 Standard)
- **Compiler:** GCC (GNU Compiler Collection)
- **Tooling:** Visual Studio Code / Windows Command Line

## 🚀 Getting Started
To compile and run any of the programs:
1. Clone this repository:
   ```bash
   git clone https://github.com/uttam102/DS-Lab.git
   ```
2. Navigate to the session directory:
   ```bash
   cd session_1
   ```
3. Compile the code:
   ```bash
   gcc 1.c -o output
   ```
4. Execute:
   ```bash
   ./output
   ```

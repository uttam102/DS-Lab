## 🔍 Detailed Weekly Breakdown

### 📘 WEEK 01: Programming Foundations
Initial introduction to C programming logic.
- **Formula Implementations:** Simple Interest, Temperature Conversion (Celsius/Fahrenheit).
- **Basic Logic:** Working with standard I/O and primitive data types.

### 📘 WEEK 02: Decision Making & Logic
Expanding logic with conditional branching.
- **Menu-Driven Calculator:** Implementing basic arithmetic using `switch-case`.
- **Flow Control:** Nested `if-else` and basic loop structures.

### 📘 WEEK 03: Sorting Algorithms (Arrays)
Focus on arranging data in memory.
- **Selection Sort:** Implementing selection-based sorting on 1D arrays.
- **Ascending/Descending:** Logic for changing sort order dynamically.

### 📘 WEEK 04: Modular Programming
Transition from linear code to reusable functions.
- **Function Prototypes:** Defining arithmetic operations as separate functions.
- **User-Interactive Menu:** Building robust user interfaces in CLI.

### 📘 WEEK 05: Dynamic Memory Management
Understanding heap memory and strings.
- **DMA (malloc):** Dynamically allocating memory for string inputs.
- **String Handling:** Manual calculation of string length without built-in libraries.

### 📘 WEEK 06: Advanced Array Operations 
Manipulating array contents at runtime.
- **Element Insertion:** Shifting logic for inserting at specific indices.
- **Dynamic Resizing:** Handling array bounds and pointer arithmetic.

### 📘 WEEK 07: Optimized Searching
Learning efficient data lookup.
- **Binary Search (Iterative):** Efficient lookup on sorted arrays with $O(\log n)$ complexity.
- **Search Logic:** Comparison of linear vs binary search paradigms.

### 📘 WEEK 08: Linear Data Structures
Implementing abstract data types using arrays.
- **Circular Queue:** Implementation of enqueue, dequeue, and display.
- **Modulo Arithmetic:** Managing wrap-around logic for circular buffers.

### 📘 WEEK 09: Dynamic Data Structures
Moving away from sequential memory toward nodes.
- **Singly Linked List (SLL):** Introduction to nodes, pointers, and heap-based structures.
- **List Operations:** Insertion, Deletion, and Traversal logic.

### 📘 WEEK 10: Hierarchical Data Structures
Advanced non-linear data representation.
- **Binary Search Tree (BST):** Implementing parent-child node relationships.
- **Tree Logic:** Recursive or iterative insertion and basic tree properties.

## 🛠️ Tech Stack
- **Language:** C (C99 Standard)
- **Compiler:** GCC (GNU Compiler Collection)
- **Environment:** VS Code / Windows CMD

## 🚀 Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/uttam102/DS-Lab.git
   ```
2. Navigate to a weekly directory:
   ```bash
   cd WEEK1
   ```
3. Compile the code:
   ```bash
   gcc 1.c -o output
   ```
4. Run:
   ```bash
   ./output
   ```
